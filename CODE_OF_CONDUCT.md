# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies to everyone who takes part in the project's spaces: issues, pull requests, discussions and any other channel the project uses.

In short: be respectful and constructive, assume good intent, and do not harass, insult or exclude anyone.

## Reporting

Report unacceptable behaviour privately to the maintainers. Until a dedicated contact is published, use GitHub's private vulnerability reporting on this repository (the **Security** tab, **Report a vulnerability**) and mark the report as a code of conduct matter. Reports are handled confidentially.

The maintainers decide on consequences following the enforcement guidelines of the Contributor Covenant 2.1, from a private warning up to a permanent ban.
