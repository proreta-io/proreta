# Roles exist at two levels. An organization role may be null (a person who belongs to the organization only through projects), and a role in a project is a direct role of the same four values, required, instead of an optional override. Before the first stable release there is no compatibility with older clients (the web app changes in the same release).
POST /api/v1/admin/organizations/{organizationId}/members added `#/components/schemas/MembershipRole` to the `role` request property `allOf` list
PUT /api/v1/admin/organizations/{organizationId}/members/{userId} added `#/components/schemas/MembershipRole` to the `role` request property `allOf` list
PUT /api/v1/admin/organizations/{organizationId}/projects/{projectId}/members/{userId} the request property `role` became required
PATCH /api/v1/members/{userId} added `#/components/schemas/MembershipRole` to the `role` request property `allOf` list
PUT /api/v1/projects/{projectId}/members/{userId} the request property `role` became required
