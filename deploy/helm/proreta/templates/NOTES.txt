{{- $ns := .Release.Namespace }}
{{- $fullname := include "proreta.fullname" . }}
{{- $url := include "proreta.publicUrl" . }}
Proreta {{ include "proreta.imageTag" . }} is installed as release "{{ .Release.Name }}" in namespace "{{ $ns }}".

1. Watch the pods until they are Running and Ready:

     kubectl -n {{ $ns }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -w

{{- if .Values.httpRoute.enabled }}

2. Check that the Gateway accepted the route (Accepted and ResolvedRefs must be True):

     kubectl -n {{ $ns }} get httproute {{ $fullname }} -o jsonpath='{range .status.parents[*].conditions[*]}{.type}={.status} {.reason}{"\n"}{end}'
{{- else }}

2. httpRoute.enabled is false: route {{ $url }} to the Services yourself
   ({{ $fullname }}-api for /api{{ if .Values.statuspage.enabled }}, {{ $fullname }}-statuspage for /status{{ end }}{{ if .Values.web.enabled }}, {{ $fullname }}-web for /{{ end }}).
{{- end }}

3. Once your Gateway and DNS route {{ regexReplaceAll "^https?://" $url "" }} to the cluster, open {{ $url }}{{ if not .Values.web.enabled }} (web.enabled is false: only the API under /api is served){{ end }}

{{- if and .Release.IsInstall (eq .Values.secrets.admin.source "generate") }}

4. Sign in as the platform admin. The one-time password exists only after the first install:

     kubectl -n {{ $ns }} get secret {{ include "proreta.secret.adminInitial" . }} -o jsonpath='{.data.login}' | base64 -d; echo
     kubectl -n {{ $ns }} get secret {{ include "proreta.secret.adminInitial" . }} -o jsonpath='{.data.password}' | base64 -d; echo

   Proreta asks you to set a new password at the first sign-in. Then delete the plaintext copy:

     kubectl -n {{ $ns }} delete secret {{ include "proreta.secret.adminInitial" . }}
{{- else if ne .Values.secrets.admin.source "generate" }}

4. Sign in as the platform admin with the credentials kept in your secret store (secrets.admin.remoteKey).
{{- end }}

   The admin owns the organization "Default" (slug "default"): add monitors there and invite colleagues by link.

{{- if .Values.config.registrationEnabled }}

WARNING: config.registrationEnabled is true: anyone who can reach {{ $url }} can
create an account and an organization, without email verification. Turn it off unless you run
Proreta for several independent organizations.
{{- end }}

rate-limit bucket (the peer address is the Gateway's).
{{- end }}

WARNING: config.trustedProxyHops is 0 with customer domains on. Behind your TLS proxy or Gateway set

customer host shares one rate-limit bucket.
